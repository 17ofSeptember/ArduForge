# Screenshots

The README references three images from this directory. They are not committed
yet. Capture them at **1600px wide** so they stay sharp on high-density
displays, where GitHub renders them at roughly half that.

| Filename | What to capture |
|---|---|
| `canvas.png` | The node canvas with a bundled example loaded. Traffic Light or Data Dashboard shows the most node variety. Include the toolbar and the code panel so the graph and the generated C++ are visible together. |
| `dashboard.png` | The Dashboard tab connected to a running board, with live values. Needs real hardware, so this one cannot be faked convincingly. |
| `import.png` | The import preview dialog, after pasting a sketch and before committing it. The statement count and the native-versus-Custom split are the point of the shot. |

Use light or dark consistently across all three.
